# phototaxis-picta
Dataset and R code for: "Water immersion triggers reversal of phototaxis sign in larvae of the sap beetle Phenolia (Lasiodites) picta" (Kishi, submitted). Phototaxis response data from 134 larvae under four conditions (normal air, water immersion, cold air, 95% CO2 air). GLM with pairwise comparisons (Holm correction).
